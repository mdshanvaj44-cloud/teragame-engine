  • Storage URLs are references, not embedded credentials.
  • Runtime must support the target platform.

HOST REQUIRED

Open a cloud gaming session

Runtime requirements

  • Remote Windows/Linux PC with suitable GPU.
  • Game installed and legally accessible on that host.
  • Browser-compatible video/audio stream.
  • Input forwarding for keyboard, mouse or touch/gamepad.
  • Network bandwidth and latency suitable for streaming.
TeraBox stores files; GitHub Pages hosts this interface. Neither provides a free GPU gaming server. This panel only opens a host URL you supply.

DOCUMENTATION

About TeraGame Engine

Phase 5.2 — unified web launcher and TGX manifest workspace.

What this project can do now

  • Maintain one catalogue for browser, Android, PC cloud and TeraBox game entries.
  • Scan user-selected files and infer likely platform from extensions.
  • Create/import/export TGX manifests.
  • Launch selected HTML files and compatible browser game URLs.
  • Save TeraBox share links and open them externally.
  • Hand off APK URLs to Android and PC stream URLs to a remote host page.
  • Manage favorites, transfers and JSON backups.

What still needs external services

  • Direct TeraBox account connection and automatic uploads.
  • Steam private library authentication/sync.
  • Actual PC GPU cloud gaming host and low-latency streaming.
  • Native APK installation and local PC execution.

This is an honest, working browser-based foundation. It does not pretend storage is compute or that a manifest is an emulator.
